# Design Integral Website
Website for Dugong Design Integral

## Setup
1. Install Python 3.8+
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
4. Open http://127.0.0.1:5000/

## Pages
- Home (/)
- About (/about)
- Portfolio (/portfolio)
- Team (/team)
- About Us (/about-us)
- Contact (/contact)

Edit templates in `templates/` and styles in `static/style.css`.
